# Data Drift Detection and Machine Learning Model Monitoring System

A project for detecting data drift between a reference dataset and production dataset and presenting the results through a monitoring dashboard.

## Project structure

```text
data-drift-monitoring-system/
├── backend/
│   ├── main.py
│   ├── monitor.py
│   ├── setup_data.py
│   ├── requirements.txt
│   ├── reference.csv          # generated by setup_data.py
│   └── production.csv        # generated by setup_data.py
├── frontend/
│   └── app/
│       ├── page.tsx
│       └── layout.tsx
├── README.md
└── .gitignore
```

## Backend

The backend uses FastAPI and exposes:

`GET /api/monitor`

The monitoring logic compares the mean of each reference-data column with the corresponding production-data column. A change greater than 20% is marked as drift.

## Generate the datasets

From `backend/`:

```bash
pip install -r requirements.txt
python setup_data.py
```

This creates `reference.csv` and `production.csv`.

## Run the API

From `backend/`:

```bash
uvicorn main:app --reload --port 8000
```

## Frontend

The PDF includes the Next.js `page.tsx` and `layout.tsx` source code, but it does not include the complete Next.js project configuration (`package.json`, `next.config.*`, Tailwind configuration, etc.). Therefore those files are intentionally not fabricated here.

The frontend source expects the backend at:

`http://localhost:8000/api/monitor`
